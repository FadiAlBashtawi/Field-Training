# ChatBot

A simple local AI chatbot powered by DistilGPT-2 using Hugging Face Transformers.

This project runs a lightweight language model locally and generates text responses without requiring external APIs.

## Features

- Runs locally on your machine
- Uses the DistilGPT-2 language model
- No API keys required
- Interactive terminal-based chatbot
- Uses Hugging Face Transformers

## Requirements

- Python 3.x
- PyTorch
- Hugging Face Transformers
